# dea-comportamental

Análisis de datos con Python y Jupyter.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

## Estructura

```
dea-comportamental/
├── notebooks/     # notebooks de análisis
├── data/          # datos (raw/ y processed/ están en .gitignore)
├── src/           # funciones reutilizables
└── requirements.txt
```
